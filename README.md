# Replication Package

This repository contains the replication package for the paper **“LLM-Assisted Empirical Software Engineering: A Systematic Literature Review.”**

## Contents

The repository includes an Excel file containing the data used during the systematic literature review process. The spreadsheet documents the search results, study selection decisions, data extraction process, and analyses conducted to answer the research questions.

## Purpose

This replication package is provided to increase the transparency and reproducibility of the review. It allows readers to inspect the study selection process, understand how the final set of papers was obtained, and verify the data used to answer the research questions.
